# John Iverson Ulleras — Personal Portfolio

Responsive personal portfolio using **HTML, CSS, and JavaScript**. It includes About, Skills, Projects, and Contact sections.

## Open locally

Open `index.html` in any modern browser.

## Publish with GitHub Pages

1. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
2. Open **Settings → Pages** on GitHub.
3. Under Build and deployment, select **Deploy from a branch** → `main` → `/(root)` → Save.
4. The expected website URL is:
   `https://johniversonulleras.github.io/John-IversonPortfolio/`

## Project link

This site links to the separate [Student Management System](https://github.com/Johniversonulleras/StudentManagementSystem) repository, which includes React, Express, Prisma ORM and MySQL. The database-powered CRUD demo cannot be hosted on GitHub Pages alone.
